# 路由方案对照与选型门槛

2026-09-23；文档调研阶段，尚未安装或验证 LiteLLM，未修改生产流量。

## 初步建议（不是最终选型）

Semifly 保留客户鉴权、商品权限、额度预留与结算、准入审批；优先验证内部独立 LiteLLM Proxy 作为供应商协议适配及路由执行器。它不公开给客户，不接管我们的商业账本。若不能完整提供每次尝试的事件或不能约束重试，则不进入生产。

OpenRouter 用作产品策略参考，也可以以后作为一个商业上游，但它不是可直接部署的本地路由组件；不能假定其内部实现、成本和数据政策可由我们控制。当前不新增商业依赖。

## 对照与取舍

| 主题 | 官方资料说明 | Semifly 决策 |
|---|---|---|
| 多部署路由 | LiteLLM 支持部署组、重试、冷却、超时和多种选择策略 [1] | 优先复用执行能力；同组必须先通过同型号、版本和功能审核 |
| 共享状态 | LiteLLM 支持 Redis 协调限流与冷却 [1] | 多实例评估需包含共享状态；供应商账户级共同限额仍需专项验证 |
| 功能兼容 | OpenRouter 提供 require_parameters；默认可能忽略不支持参数 [2] | 必需能力必须硬筛选，不静默丢弃 tools、结构化输出等要求 |
| 价格限制 | OpenRouter max_price 是价格过滤，延迟偏好不是性能保证 [2] | 成本上限为硬约束，延迟是调度目标；未知成本不能按零成本参与 |
| 跨模型回退 | OpenRouter 单独提供模型候选回退机制 [3] | 第一版禁止跨型号自动回退；未来仅明确授权的场景商品开放 |
| 流式错误 | OpenRouter 文档说明响应提交后可能用 SSE error 表达，HTTP 仍为 200 [4] | 成功判定必须检查协议结束、错误事件和 usage，不能只看 HTTP 状态 |

## 我们自己的强制边界

- 只有一个层级拥有重试决策；Semifly、路由器、供应商 SDK 不叠加重试。网关删除客户端传入的内部重试、供应商选择和配置覆盖字段/请求头。
- 初始实验最多两个上游尝试，共用请求总截止时间；连接、首事件、流中空闲和总时长分别记录。数值通过测试确定，不照抄供应商默认值。
- 主备必须有真实独立容量；同账户多 Key 不当作独立容灾。429 按确认的配额范围冷却，不借换 Key 绕过供应商限额。
- 所有备选同样满足模型、数据地域、保留政策和功能约束，不能因为故障放宽客户的数据承诺。
- 对客户已提交响应后不重新开始另一个答案。工具调用部分输出也算提交；取消、超时和断流记为明确状态。
- 上游可能在超时后继续收费，不能承诺重试零成本。客户结算一次，上游尝试分别记账，未知 usage/cost 保留未知并进入对账。
- 不通过失败重试绕过安全拒绝；参数错误不盲目换供应商。
- 独立 Proxy 增加一个故障点，需认证、网络隔离、可观测性、版本锁定与回滚；配置和日志不得暴露密钥。

## 候选部署方式

| 方式 | 优点 | 代价 | 判断 |
|---|---|---|---|
| 全部自研 | 行为完全可控 | 协议和故障处理维护量大 | 暂不优先 |
| 应用内 Router SDK | 少一跳网络 | 依赖与主业务耦合、升级影响范围大 | 备选 |
| 内部独立 Proxy | 与主站隔离、可独立替换回滚 | 多一个服务，需事件关联与共享状态 | 优先做实验 |

安装前需核实候选具体版本、依赖安全情况、许可证和所需能力是否属于商业功能。文档描述不代替该版本实测，当前不声称已完成这些核实。

## 双模拟上游验收矩阵

使用本地合成数据，无真实供应商 Key、无外部付费调用。下表是待执行计划，不是已通过结果。

| 场景 | 期望行为 | 必查证据 |
|---|---|---|
| A 正常 | 只请求 A | 1 request、1 attempt、1 settlement |
| A 503，B 正常 | 有界切换 B | 错误原因、A/B 次序、总耗时 |
| A 429 | 配额组冷却；独立 B 接替 | 不反复调用同配额组 |
| A 401 | 凭据隔离，不反复尝试 | 隔离事件及管理员告警 |
| 请求参数错误 | 不切换 | 无 B 调用 |
| A 响应前超时 | 剩余时间内选择 B | A 成本未知而非零；最多两次 |
| A HTTP 200 + SSE error | 不能记成功 | 协议错误与结算状态 |
| A 输出一半后断流 | 结束并报中断，不拼接 B | 部分输出、usage 缺失处理 |
| B 不支持 tools | 排除 B | 能力筛选原因 |
| B 价格超限/未知 | 排除 B | 费率版本、拒绝原因 |
| A/B 全部故障 | 一次明确失败，释放可释放预留 | 无重复扣费、无无限重试 |
| 客户取消 | 停止转发与后续重试 | 上游取消结果、成本待核对 |
| 两个网关实例共享限额 | 合计不突破配置预算 | 共享计数、冷却一致性 |
| 路由器重启/事件重复 | 不重复结算，尝试记录可追踪 | 幂等与故障恢复证据 |

验收后才能决定是否引入生产依赖。先覆盖请求/尝试账本，再接正式路由，最后灰度；保留原单通道路由回滚能力。
